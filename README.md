# DevOps Learning Journey

I'm Juan Pablo, Software Testing Engineer with 10+ years of experience in the medical device manufacturing industry, transitioning into DevOps Engineering. This repository documents my hands-on learning journey.

Inside this repo you will find the weekly progress in my learning path, from cheatsheets, to runbooks and briefs of the deployments I have or am currently working on.

I see the DevOps role as the man behind the curtain, making the devs' work shine with speed and responsiveness and the users rejoice with the high performance of the services they consume. I want that — to be the silent partner, to resolve, automate and enhance. This repo is the proof of work: a Flask application deployed as a systemd service behind an Nginx reverse proxy, running on Ubuntu under WSL2, documented and version controlled from day one.
